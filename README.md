# Facebrowser Helper (GTA World)

Юзерскрипт для [fbv2.gtaw.io](https://fbv2.gtaw.io): ставит лайки в ленте и отправляет заявки в друзья
от имени активного персонажа. Работает в уже открытой и залогиненной вкладке. Есть дневные лимиты,
паузы между действиями и пробный прогон (dry-run).

## Установка

1. Поставь Tampermonkey или Violentmonkey.
2. Создай новый скрипт и вставь содержимое `gtaw-fb-helper.user.js`.
3. Открой fbv2.gtaw.io и любую страницу сайта (например, «Друзья»): скрипт сам определит персонажа.
   Панель появится в правом нижнем углу.

По умолчанию включён dry-run: скрипт только пишет в лог, что сделал бы, и ничего не отправляет.

## Настройки панели

| Поле | Что делает |
| --- | --- |
| Лайков / заявок за запуск | сколько действий за одно нажатие «Старт» |
| Потолок лайков / заявок в день | дневной лимит на персонажа, общий для всех вкладок |
| Пауза от / до, с | случайный интервал между действиями (не меньше 5 с) |
| Макс. висящих заявок | если неотвеченных заявок столько или больше, заявки не шлются |
| Не трогать | id или ники через запятую: их посты не лайкаются, им не шлются заявки |
| Лайкнуть пост перед заявкой | перед заявкой лайкнуть свежий пост этого человека |
| Заявки только онлайн-людям | брать кандидатов только из тех, кто сейчас в сети |

Заявка тому же человеку повторно не отправляется 30 дней, даже если он её отклонил.
Одновременно работает только одна вкладка сайта: во второй «Старт» сообщит, что запуск уже идёт.

## Автотест

Тест поднимает фейковый API и проверяет скрипт в headless Chromium:

```sh
npm install
npx playwright install chromium
npm test
```
