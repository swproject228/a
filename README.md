# Facebrowser Helper (GTA World)

Юзерскрипт для [fbv2.gtaw.io](https://fbv2.gtaw.io): ставит лайки в ленте и отправляет заявки в друзья
от имени активного персонажа. Работает в уже открытой и залогиненной вкладке. Есть дневные лимиты,
паузы между действиями и пробный прогон (dry-run).

## Установка

1. Поставь Tampermonkey или Violentmonkey.
2. Создай новый скрипт и вставь содержимое `gtaw-fb-helper.user.js`.
3. Открой fbv2.gtaw.io и любую страницу сайта (например, «Друзья»): скрипт сам определит персонажа.
   Панель появится в правом нижнем углу, её можно перетащить за заголовок.

По умолчанию включён dry-run: скрипт только пишет в лог, что сделал бы, и ничего не отправляет.

## Настройки панели

| Поле | Что делает |
| --- | --- |
| Лайков / заявок за запуск | сколько действий за одно нажатие «Старт» |
| Потолок лайков / заявок в день | дневной лимит на персонажа, общий для всех вкладок |
| Пауза от / до, с | случайный интервал между действиями (не меньше 5 с) |
| Макс. висящих заявок | если неотвеченных заявок столько или больше, заявки не шлются |
| Не трогать | id или ники через запятую: их посты не лайкаются, им не шлются заявки |
| Лайкнуть пост перед заявкой | перед заявкой лайкнуть свежий пост этого человека |
| Заявки только онлайн-людям | брать кандидатов только из тех, кто сейчас в сети |

Верхние пределы полей: 1000 лайков и 500 заявок в день. Поднять их можно константой `HARD_MAX`
в начале скрипта.

Заявка тому же человеку повторно не отправляется 30 дней, даже если он её отклонил.
Одновременно работает только одна вкладка сайта: во второй «Старт» сообщит, что запуск уже идёт.


## Авторежим

Раздел «Авторежим» на панели: скрипт повторяет запуски каждые X–Y минут, пока не нажат «Стоп».

- **Рабочие часы.** «Работать с / до» ограничивает время запусков, например с 10 до 23 или с 22 до 3 (через полночь).
  0 и 24 означают «круглые сутки».
- **Лимиты.** Когда дневные потолки выбраны, следующий запуск будет после полуночи.
- **Ошибки.** При ошибке сайта (429, Cloudflare, разлогин, пять отказов подряд) авторежим выключается сам.
  Галочка «Уведомить» покажет об этом уведомление браузера. Если пропала связь, он делает до трёх попыток раз в 5 минут.
- **Выключение.** Кнопка «Стоп» или снятая галочка «Повторять запуски». Если галочку снять во время запуска,
  текущий проход закончится, а новых не будет.
- **Перезагрузка страницы.** Авторежим продолжится с того же места и с теми же настройками, но не раньше начала
  рабочих часов. После «Стопа» или снятой галочки не продолжится.

## История

Раздел «История за 14 дн.»: сколько лайков и заявок было за каждый день у текущего персонажа и сумма за период.

## Запись запросов сайта

Нужна, чтобы подключить новые функции к API сайта (например, автоответы в чате). Включи запись, обнови страницу,
открой чат, отправь сообщение и дождись ответа, затем нажми «Копировать запись». Записываются адреса запросов,
коды ответов и структура JSON: имена полей и их типы. В адресах остаются только служебные слова из строчных букв
(`conversations`, `unread-count`), всё остальное (id, ники с цифрами или заглавными, токены) заменяется на `{id}`.
Значения параметров и полей заменяются на `str` и `num`, кроме коротких служебных (`sort=recent`, `status=sent`).
Тексты сообщений, токены и cookie в запись не попадают. Перед отправкой просмотри скопированный текст.

## Автотест

```sh
npm test
```
